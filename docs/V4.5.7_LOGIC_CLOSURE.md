# V4.5.7 Logic Closure Patch

本Patch只修执行衔接，不重写人物、变身、母图、综合色、Combat或详细Prompt内容Authority。

## 1. Storyboard Real Generation
`STAGE_04_STORYBOARD → GENERATION_JOB_DISPATCH → GENERATION_JOB_EXECUTOR → Candidate → QC_PASS_WAITING_APPROVAL → Review Board → User Approval Set → Approval Record → Promotion`。
T19使用`MANDATORY_STORYBOARD_QC_COVERAGE_PASS + STORYBOARD_GENERATION_JOBS_QC_READY`，只证明全部正式Shot的计划白描Panel已真实生成并过视觉QC；T20用户批准后再要求`STORYBOARD_GENERATION_JOBS_PROMOTED + MANDATORY_STORYBOARD_APPROVED_COVERAGE_PASS`，禁止先Promotion后审批。

## 2. Execution Plan Fingerprint
Frozen Plan绑定`director/storyboard/shot_execution/scene_color/world_state`五类Source Fingerprint。任一变化，Plan与下游Prompt/Video Job失效。

## 3. Prompt Artifact Hard Bind
Final Seedance Master Prompt必须先成为`VIDEO_PROMPT_ARTIFACT`，记录真实Prompt Fingerprint和Execution Plan Fingerprint。Video Generation Job缺任一绑定不得READY。

## 4. Ending Frame Continuity Loop
Approved Video先提取真实Ending Frame并写Continuity Snapshot。有下一Unit时通过`ADVANCE_VIDEO_UNIT`回到Storyboard；只有全部Unit完成才进入Post。

## 5. Gate Producer Closure
`controller/gate_producer_registry.yaml`登记Stage04/05所有Transition Requirement的Producer。`validators/gate_producer_lint.py`阻止悬空Gate。

## 6. White-line Storyboard Hotfix
- `storyboard_coverage_lint.py`以Formal `SHOT_STATE`为期望集合；空Registry、缺Shot、DRAFT Job、Approval Fingerprint不一致都不能PASS。
- Mandatory白描Panel的Scene Color只做`VALUE_LIGHTING_LINEAGE_ONLY`血缘，不直接绑定彩色色卡。
- `STORYBOARD_CLEAN_SEQUENCE_BOARD`只允许确定性拼版，不再作为Image Generation Job。
- Stage 05新增`storyboard_handoff`八字段合同与`storyboard_to_video_prompt_handoff_lint.py`，逐项检查Final Prompt真实继承，而非只检查关键词。
- Mandatory白描Panel禁止成为Primary Video Conditioning；Primary Visual继续由Shot Execution/First/Target/Key Pose资产承担。
