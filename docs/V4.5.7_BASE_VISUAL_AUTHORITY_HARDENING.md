# V4.5.7 Base Visual Authority Hardening

本次升级把“一次性资产轻量化”改为“Base Authority完整优先”。

## Hard Rules
1. 每个被Formal Event/Shot使用的Location/Sub-location，无论Tier S/A/B/C，都必须有一张Approved空场景Clean Master。
2. 每个清楚可见的一次性配角/功能人物，都必须有一张Approved Functional Minor Human / Minor Human Master。
3. Shot Assembly、Rendered Previs、匿名白描只能补关系/动作/姿态，不能替代上述Base Master。
4. 只有真正不可辨认的Deep Background Crowd允许TEXT_ONLY。
5. 所有Event Node actor_ids必须进入actor_authority_index，防止一次性人物漏规划。
6. 资产库允许丰富；同一Entity通过reuse_key、asset_family_id、version、lineage复用与去重。Stage 05仍由Reference Resolver输出Minimum Sufficient Direct Pack。
