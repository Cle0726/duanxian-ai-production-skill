# V4.5.7 Storyboard Entity Binding → Video Closure

本升级把匿名白描中的几何人物与真实视频资产完全接通：

`Anonymous Slot → STORYBOARD_ENTITY_BINDING_MAP → Entity ID → Approved Canon Candidate → Entity Binding Resolver → Video Execution Plan → Final Prompt → Generation Job required_bindings`。

关键规则：
- 白描像素不含人物身份；
- Slot ID只存在于离图Metadata；
- Human Slot必须记录精确世界站位、画面投影、朝向、姿态、动作与动作阶段；
- 反打只重新投影画面左右，不交换Entity；
- Stage05按风险选择`PRIMARY_VISUAL_BAKED`或真实`DIRECT_REFERENCE @资产`；
- Direct @必须同时存在于Final Prompt与实际Generation Job；
- Final Prompt必须逐人物明确“谁 / 在哪里 / 朝哪里 / 做什么”。
