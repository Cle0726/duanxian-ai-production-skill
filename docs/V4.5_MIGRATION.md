# V4.5 Migration｜Relation-Driven Visual Production

## 目标
V4.5不推翻V4.4的Primary Visual Conditioning，而是补上更上游的缺口：**镜头执行图必须从正确的镜头关系与资产义务派生。**

## 迁移规则
1. 已APPROVED Video保持有效，不追溯重做。
2. 已APPROVED Storyboard但尚未生成Video：若存在跨Shot的Clue/POV/Match/Location Reveal等关系，补建SHOT_RELATION_GRAPH并派生缺失Obligation；只补受影响资产与Conditioning Pair。
3. 尚未Freeze的Episode：Stage 02C必须先建立Shot Relation Graph并派生Visual Asset Obligation。
4. V4.4 Environment Clean Canon / Video Conditioning资产全部继承；不因版本升级机械重做。
5. 若两个Environment Master各自Approved但关系无法被静态证据证明，标`LOCATION_RELATION_UNPROVEN`，只补最小关系型Coverage。

## 兼容性
- V4.4的Primary Visual、Asset Usage权限矩阵继续有效。
- 新结构不新增独立Markdown Engine，避免Authority继续膨胀。
- 旧Episode可将Shot Relation状态记为UNKNOWN，直到相关镜头进入下一生产动作时最小补齐。
