# V4.5.7 Contact Sheet First Storyboard Upgrade

本次升级把Storyboard生产方式从“单Panel优先”扩展为“Contact Sheet First”优先，特别适用于：
- 多镜头短Scene；
- 打斗 / 追逐 / 舞蹈等高动作密度段落；
- 长镜头分解成多个动作Beat；
- 需要一次看清Coverage多样性与剪辑节奏的Sequence。

核心原则：
1. 生成整张白描Contact Sheet（4/6/9/12/16/25...）；
2. 像素中仍只有匿名几何人形；
3. Metadata中保留精确的Panel→Shot/Beat→Entity Binding；
4. `tools/storyboard_contact_sheet_splitter.py`把Approved Contact Sheet切成独立Panels；
5. Stage 05 继续使用切出的单Panel与按风险选择的@资产，不把整张宫格当Primary Visual硬塞给视频模型。
