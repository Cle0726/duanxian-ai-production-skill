# V4.5.7 No Reference Video + Managed Audio Reference

## Policy
- Reference video is forbidden for all Video Generation Jobs because it consumes video quota.
- Generated/output/QC videos may still exist; only using a video asset as an input reference is forbidden.
- Motion/camera guidance is carried by storyboard, action key poses, camera path metadata, ending-frame stills and detailed text.
- Audio reference is allowed only through `AUDIO_ASSET_MANIFEST`.

## Audio management
Every reusable audio asset can be indexed by stable Asset ID, display name, native @ token, type, authority role, scope, version, fingerprint and binding status. Stage 05 and Stage 06 consume the same manifest.
