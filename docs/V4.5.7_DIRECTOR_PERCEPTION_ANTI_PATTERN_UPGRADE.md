# V4.5.7 Director Perception & Anti-Pattern Upgrade

## 目的

本补丁吸收 Cinema-DNA 类方法中“关系压力、观看立场、注意力流量、防模板化记忆”的可泛化部分，但不引入其固定三联、真人胶片默认、导演名字配方或外部参考复制规则。

架构原则保持不变：不新增 Stage，不新增独立 Cinema DNA Engine；新事实被分配给现有 Director / Cinematography / Editorial / Runtime / Validation Owner。

## 新导演链

`Audience State → UNRESOLVED_STATE → RELATIONAL_PRESSURE → Viewpoint Role → CAMERA_ETHICS → ATTENTION_FLOW → SHOT_SCALE_JUSTIFICATION → Camera/Lens → VISUAL_FORCE_STACK → VISUAL_SALIENCE_BUDGET → INFORMATION STATE/DELTA → Edit → Storyboard Proof → Generation Envelope`

## Hard Gates

- `DIRECTOR_PERCEPTION_PASS`：成为 `T08_DIRECTOR_CORE` 的前置条件。
- D1/D2必须建立 Unresolved State 与 Relational Pressure。
- 每个Formal Shot必须有 Camera Ethics、Attention Flow、Camera Placement双重理由、Shot Scale理由、Visual Force Stack与Visual Salience Budget。
- CU/ECU/Detail必须说明为什么更宽失败、牺牲了什么空间信息、换来什么不可替代的信息收益；“更有情绪/更电影”无效。
- CAUSAL Sequence必须通过 Shuffle Test；Associative/Montage按自身组织逻辑验收。

## Advisory Telemetry

`SHOT_GRAMMAR_HISTORY`只记录Locked/Approved镜头的轻量语法签名。`CREATIVE_DRIFT_TELEMETRY`只发Warning：

- SHOT_SCALE_BIAS
- CAMERA_ETHICS_BIAS
- VIEWPOINT_ROLE_BIAS
- COMPOSITION_PATTERN_COLLAPSE
- CAMERA_CHARACTER_BIAS
- EDITORIAL_PATTERN_COLLAPSE

Warning不会自动换镜头。重复若属于有意风格，记录Intentional Pattern即可。

## Editorial扩展

每个Shot维护：

- Information State IN
- Information Revealed
- Information Withheld
- Information State OUT
- Editorial Weight：TRANSIENT / NORMAL / EMPHASIS / HOLD
- Breathing Function：NONE / DECOMPRESSION / ANTICIPATION / SPATIAL_REORIENTATION / EMOTIONAL_DELAY / TEMPORAL_REALISM

Sequence声明 `CAUSAL / ASSOCIATIVE / MONTAGE`，并保存Shuffle Test结果。

## Storyboard联动

白描Panel仍然零文字、零箭头。Camera Ethics、Attention Flow、Shot Scale Justification、Visual Salience等只存在离图Metadata/QC。Storyboard用视觉证据验证这些导演判断，不重新设计它们。

原有规则保持：2+ Formal Shot的正式Sequence必须先形成Approved白描宫格；非ONER Generation Envelope还必须有CUT子集宫格。

## Stage 05联动

Prompt Compiler新增：`Execution Density ≠ Visual Salience Density`。详细Video Prompt可完整保留动作、时序、物理、声音与连续性，但画面显著性仍按Primary/Secondary/Ambient/Suppressed层级组织。

当用户要求“更电影/更像断弦之歌”时，Style Escalation不得只增加形容词；必须定位Camera Ethics、Blocking、Attention Flow、Performance、Reveal、Hold/Cut、Color或Music Identity中的真实缺口后加强机制。

## Deterministic Components

- `validators/director_perception_lint.py`
- `tools/shot_grammar_history.py`
- `validators/editorial_plan_lint.py` 已扩展 Information/Shuffle/Weight/Breathing检查

## Compatibility

保留 V4.5.7 skill_version 与现有 Generation Envelope、白描Storyboard、Stage 05 Prompt Authority、Execution Plan、Color Lineage和Failure Router。该补丁为兼容扩展，不改变既有六阶段与Approved/QC语义。
