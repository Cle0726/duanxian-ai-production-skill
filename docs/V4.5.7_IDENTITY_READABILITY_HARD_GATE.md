# V4.5.7 Identity Readability Hard Gate

本升级不推翻现有Stage 03人物/场景资产体系，只补一个Stage 04B→05之间的视觉证据缺口：Primary Visual虽然是高清单帧，但在多人物远景或平台缩放后，命名人物脸部可能已经不足以核验身份。

闭环：

`Primary Visual → Platform-effective Preview → Identity Readability Assessment → PASS / FAIL`

FAIL时：
- Primary Visual保留Composition/Blocking Authority；
- 不得成为对应人物唯一Identity Authority；
- Direct Bind Character/FMH Identity Master，或重生Readable Primary并重新评估；
- Storyboard/Environment均不能作为Identity fallback。

SH07型多人远景测试被用于验证：原始大图/大文件不能让Gate自动PASS；只有平台尺度人物可读，或每个不可读人物都有真实Direct Identity Binding，才能进入Video Generation Ready。
