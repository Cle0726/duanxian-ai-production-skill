# V4.5.2 Migration — Script-Grounded Virtual Set & Asset Justification

V4.5.2不新增新的一级Stage，也不新增九个Markdown Engine。它升级现有Spatial Canon与Episode Asset Pack：

1. `SPATIAL_CANON` schema v2新增`character_routes`与`planning_diagrams`；
2. Tier S/A重要Set需要可审计Outdoor Topology / Floor Plan等Planning Diagram；
3. Event Node必须落到Location/Zone/Anchor，跨节点移动可建立Character Event Route；
4. Coverage支持Event / Reciprocal / Predictive派生，并登记Spatial Parent + Visual Parent；
5. Asset Registry v5新增`justification`与`derivation`，正式TO BUILD资产必须回答WHY_REQUIRED / REQUIRED_BY / DOWNSTREAM_USE；
6. Stage 03采用Cascade Approval，不允许上游结构未批准时批量制造下游图片；
7. Interior / Exterior Look Domain进入正式Freeze；
8. 主要/反复角色Required Voice Identity也在Asset Freeze前解析；
9. V4.5.1 Clean Storyboard、Relation Closure、Video Conditioning全部保留。

旧项目迁移时不要伪造拓扑/平面图：只有真实已存在并可审核的结构证据才可登记APPROVED；否则状态为REQUIRED / IN_PROGRESS。
