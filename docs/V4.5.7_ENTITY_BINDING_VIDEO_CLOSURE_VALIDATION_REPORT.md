# V4.5.7 Entity Binding → Video Closure Validation Report

## Scope

本轮在`Spatial Continuity + Multiview Canon`基础上完成匿名白描到真实视频资产的端到端闭环：

`Anonymous Storyboard Slot → STORYBOARD_ENTITY_BINDING_MAP → Entity ID → Approved Canon Candidate → Nearest Visual Parent / Reference Resolver → VIDEO_EXECUTION_PLAN.entity_binding_handoff → Final Video Prompt → GENERATION_JOB.required_bindings`。

## Added hard closures

- 白描Slot只存在离图Metadata，禁止进入图片像素或Final Prompt。
- Human Slot必须记录`world_zone / frame_region / depth_region / body_orientation / pose_state / action_state / action_phase`。
- Slot与Entity一对一，禁止同一人物跨Slot别名导致串人。
- 反打只允许`frame_projection`变化；`world_position`仍由Spatial Continuity保持。
- `PRIMARY_VISUAL_BAKED`对Critical Entity必须有`coverage_evidence_ref`。
- `DIRECT_REFERENCE`必须解析到Approved Asset + Native `@Token`。
- Direct `@`必须同时存在于Final Prompt、Execution Plan direct_reference_ids和实际Generation Job required_bindings。
- Stage 05最终Prompt必须逐Human Slot恢复“谁 / 在哪里 / 朝哪里 / 做什么”。
- 新增确定性`Nearest Spatial-Visual Parent`按Camera/View yaw选择最近Approved视角，避免永远回Hero重新猜。
