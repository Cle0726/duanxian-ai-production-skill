# V4.5.7 Multimodal All-Round Reference Default

## 目的
把项目默认视频Reference能力从模糊的“Named Asset平台”区分成两个层次：

1. **Capability Class**：`MULTIMODAL_ALL_ROUND_REFERENCE`；
2. **Reference Transport / Prompt Surface**：Named Asset、Ordered Image、Tool-native等由当前Host真实能力决定。

## 定义
全能参考描述底层模型的多模态职责理解能力；《断弦之歌》项目执行策略只开放文字、图片、音频Reference，并将Reference Video固定禁用。

它不意味着：
- Primary Visual能承担所有Authority；
- Storyboard可以补人物身份；
- 空场景图可以补人物身份；
- 资产库全部进入一个Job；
- Provider素材数量没有限制。

## 默认链路
`Asset Library → Field Coverage → Identity Readability → Reference Resolver → Minimum Sufficient Multimodal Reference Set → Host Adapter → Video Generation Job`

## Provider限制
具体图片/音频数量、大小、格式、时长等只属于当前Provider Profile；Reference Video在项目层固定为0，不进入Generation Job。
