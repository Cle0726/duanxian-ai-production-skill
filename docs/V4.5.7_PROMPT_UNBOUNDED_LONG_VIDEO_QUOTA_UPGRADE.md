# V4.5.7 Prompt Unbounded + >15s Video Quota Confirmation

## Rules
- `PROMPT_LENGTH_CEILING = NONE`: Source/Master Prompt has no Skill-level character ceiling.
- `LONG_VIDEO_QUOTA_CONFIRMATION_THRESHOLD = 15s`: duration >15s is legal, but requires explicit user quota confirmation before a real VIDEO Generation Job.
- The 15s threshold is not a model hard max and does not trigger automatic segmentation.
- If the user has no quota, generation stops and the user is asked whether to split on a natural beat or shorten.

## Mechanical enforcement
- `validators/video_quota_confirmation_lint.py`
- `validators/video_execution_plan_lint.py` anti-bypass check
- `validators/video_generation_job_prompt_lint.py` final anti-bypass check
- `LONG_VIDEO_QUOTA_CONFIRMATION_PASS` required by `T23B_VIDEO_READY`
