# V4.5.7 Editorial Language Upgrade｜镜头语言 + 剪辑方法增强补丁

## Problem
原V4.5.7已经具备Cinematography Grammar、Cut Motivation、Shot Relation和Cut Density Arc，但缺少独立的Sequence-level Editing Authority。结果容易出现：单个Shot执行很完整，但Sequence层面视角长期停留在同一种观察位置；“会运镜”不等于“会切视角”。

## Upgrade
新增`templates/editorial_grammar_engine.md`作为唯一Editorial Authority，并新增结构化`EDITORIAL_PLAN`：

`Audience State → Editorial Intent Draft → Viewpoint Arc → Shot Progression → Edit Function → Cut Trigger → Cut Timing → Continuity Strategy → Locked Editorial Plan → Storyboard Proof → Shot Generation → Stage 06 Assembly`

## Default Production Strategy
默认`ASSEMBLY_FIRST`：
- 一个Formal Shot优先对应一个稳定Video Clip；
- 每个Shot可拥有不同Viewpoint Role / Camera Geometry / Lens / Performance Access；
- Stage 06依据Editorial Plan剪接，形成真实视角变化；
- 单个Shot失败只Retry该Shot，不破坏整段Multi-shot连续性。

条件模式`IN_MODEL_MULTISHOT`只在目标模型已验证稳定、且每个子Shot有独立Director/Storyboard/Conditioning Evidence时启用。

## New Editorial Vocabulary
- Viewpoint：OBJECTIVE / CHARACTER_ALIGNED / OTS / POV / REACTION / DETAIL / ENVIRONMENT / DISTANT / SUBJECTIVE
- Trigger：Information / Gaze / Action / Reaction Threshold / Power / Sound / Rhythm / Spatial / Ellipsis / Motif
- Timing：Before / On / After Action；Gaze Landing；Reaction Leak；Sound Prelap/Tail；Impact；Silence
- Transition：Hard / Match / Smash / J / L / Dissolve / Fade / Intentional Jump
- Continuity：Action / Eyeline / Screen Direction / Spatial Anchor / Motion Vector / Sound / Performance / Prop / Light-Color / Intentional Discontinuity

## Integration
- Stage 02B：产出并校验`EDITORIAL_PLAN`；
- Stage 02C：与`SHOT_RELATION_GRAPH`交叉校验；
- Stage 04：Storyboard证明Viewpoint Transfer和Edit Boundary；
- Stage 05：默认只生成当前Formal Shot，同时保护Edit Entry / Protected Moment / Edit Exit / Handles；
- Stage 06：按Planned Editorial EDL对Approved Takes执行Picture Assembly。

## Key Failure Codes
Hard failures route back to the minimum owner:
- `EDITORIAL_PLAN_CONFLICT`
- `CUT_TRIGGER_MISSING`
- `CUT_INFORMATION_FUNCTION_GAP`
- `EDIT_RELATION_MISMATCH`
- `EDIT_CONTINUITY_CONFLICT`
- `EDITORIAL_BOUNDARY_EXECUTION_GAP`
- `IN_MODEL_MULTISHOT_EVIDENCE_GAP`

Warnings do not force extra cuts:
- `VIEWPOINT_STAGNATION_RISK`
- `MECHANICAL_REVERSE_SHOT_RISK`
- `CUT_DENSITY_FLAT_RISK`
- `REACTION_OVER_COVERAGE_RISK`

## Design Rule
剪辑丰富度不等于切得更多。

真正需要避免的是：连续多个Shot虽然景别略变，但仍然保持同一个主体、同一观察位置、同一信息功能、同一情绪访问方式。Editorial Plan要求每次切换明确改变至少一种观看关系：信息、对齐、权力、空间、反应访问、动作因果或节奏。
