# V4.5.3 Migration — Visual Evidence Handoff & Text-only Continuation

V4.5.3不改变六阶段主流程，也不要求已有资产全部重做。新增的是视觉事实持久化接口：

1. 多模态/人工看过正式图片后，写`VISUAL_EVIDENCE`并绑定文件Fingerprint。
2. Text-only Controller只消费Current Evidence，不创建新视觉PASS。
3. 缺Evidence只把当前依赖资产送入`VISUAL_REVIEW_QUEUE`。
4. `REFERENCE_RUNTIME`增加Required/Forbidden Visual Facts与Evidence Coverage。
5. Final `@资产`在Text-only模式必须通过`visual_evidence_lint.py --phase reference`。

旧V4.5.2资产可继续存在；没有Evidence时状态为UNKNOWN/MISSING，不自动降级Canon，也不自动重做。
