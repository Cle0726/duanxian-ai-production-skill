# V4.5.7 Generation Envelope + Multi-shot Storyboard Grid Upgrade

## 目标
解决“正式镜头设计已经存在，但视频生成仍长期停留在单一视角”的执行断层，同时不破坏既有Director / Editorial / Spatial / Asset / Approval Authority。

## 核心变化

### 1. Formal Shot与Generation Call解耦
新增`GENERATION_ENVELOPE`：

`EDITORIAL_PLAN → Formal Shots → GENERATION_ENVELOPE → CUT_CONTRACT[] → VIDEO_EXECUTION_PLAN → VIDEO_PROMPT_ARTIFACT → GENERATION_JOB`

支持：
- `ONER`
- `SEQUENTIAL_MULTISHOT`
- `TIMED_MULTISHOT`
- `FREESTYLE_BROLL`

### 2. 两层白描宫格硬门
**Sequence级：** 任何正式Sequence只要有2+ Formal Shot，无论后续逐镜生成还是模型内多镜头，都必须先有整段`STORYBOARD_SEQUENCE_PROOF`。

**Envelope级：** 任何非ONER Generation Envelope都必须为每个CUT绑定独立Approved白描Panel，再按CUT顺序用`tools/storyboard_grid_assembler.py`确定性拼出`STORYBOARD_CLEAN_SEQUENCE_BOARD`。

两层宫格都禁止文字、编号、箭头、CUT标签与时间码，且不能作为Video Primary Visual。

### 3. 确定性Grid Manifest
`storyboard_grid_assembler.py`新增`--manifest-output`，记录：
- 输入Panel真实顺序；
- 每个Panel SHA-256；
- 输出Board SHA-256；
- 行列数与Assembler身份。

因此Controller可以证明“这张宫格确实由这些Approved Panels按这个CUT顺序组成”。

### 4. CUT Contract
每个模型内CUT至少拥有：
- Narrative Function
- Viewpoint Role
- Camera Character
- Camera Start / Path / End
- Action / Performance
- Information Reveal
- Cut In / Out Trigger
- Continuity Handoff
- Storyboard Panel
- Timed模式下的Start / End

连续CUT只变焦距、不变Camera Character和Information Relationship会产生`PSEUDO_MULTISHOT_STAGNATION_RISK`。

### 5. Seedance Adapter
新增`adapters/generation/seedance_multishot_profile.yaml`，只负责Provider执行翻译：
- FOV Anchor：107 / 84 / 63 / 47 / 29 / 18 / 12；
- 受控CUT格式；
- Positive Lock优先；
- 白描宫格只做辅助Reference；
- Multi-shot不稳定时拆回Single-shot Envelopes。

Core Director事实不绑定某个平台。

### 6. Stage 06 Sub-cut Salvage
Multi-shot Take不再只有“整条要/不要”。可逐CUT登记：
- CLEAN_KEEP
- REPLACE
- HANDLE_ONLY

失败CUT可独立拆出Single-shot Envelope重生，再替换回原Editorial结构。

- `STORYBOARD_SEQUENCE_GRID_QC_PASS`

Storyboard Approval新增：
- `STORYBOARD_SEQUENCE_GRID_APPROVED_PASS`

Stage 04B Conditioning Entry新增：
- `GENERATION_ENVELOPE_RESOLVED`
- `MULTISHOT_STORYBOARD_GRID_GATE_PASS`

Stage 05 Video Ready新增：
- `GENERATION_ENVELOPE_VALID`
- `MULTISHOT_STORYBOARD_GRID_GATE_PASS`

## 回退原则
- Storyboard Grid问题 → 只补/修受影响白描Panel并重新拼版；
- Envelope格式/Shot集合问题 → 只重建受影响Envelope；
- Provider Multi-shot能力不足 → 拆为Single-shot Envelopes；
- Multi-shot Take局部失败 → Sub-cut Salvage / 只重生失败CUT；
- 不因执行失败重新设计已锁Editorial Plan。
