# V4.5.7 Rich Asset Library / Performance / Narrative FX Backport

## Purpose

This patch preserves three production principles from the early Episode 1 asset-bible workflow without restoring its duplicated prompt architecture.

1. Stage 03 builds a requirement-complete reusable visual authority library; Stage 05 alone minimizes the per-job direct reference payload.
2. Shot-specific performance risks may require static expression/action/contact support assets, but support is requirement-driven rather than a fixed sheet quota for every character.
3. Repeating, signature, continuity-sensitive, or high-risk narrative visual phenomena may own static Narrative FX canon and state coverage rather than being re-invented from text in every shot.

## Canonical Principle

`RICH CANON LIBRARY != LARGE VIDEO REFERENCE PACK`

- Stage 03 has no fixed image-asset-count ceiling.
- Asset production is still bounded by actual episode requirements and authority coverage.
- Stage 05 resolves the smallest sufficient direct reference set for the current generation job.
- Reference video remains forbidden by project policy.

## Authority Boundaries

Performance Support can own static expression, action pose, or contact pose evidence. It cannot own character identity, wardrobe canon, environment geography, camera, or timing.

Narrative FX assets can own a phenomenon's static morphology, selected visual states, and static scene interaction. They cannot own camera, event timing, character identity, or environment geography.

Multi-panel performance sheets and multi-state FX sheets are canon/selection support. They are not default direct video references; select a single state/frame or bake it into the Shot Execution Frame.

## Explicit Non-Backports

This patch does not restore giant duplicated style prompts, fixed four-view coverage for every asset, fixed six-expression/six-action quotas for every minor character, or a single character image permanently owning global style authority.
