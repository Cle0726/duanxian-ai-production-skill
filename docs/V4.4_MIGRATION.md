# V4.3.1 → V4.4.0 Migration

## 核心变化
V4.4不废弃旧Approved Canon / Storyboard / Support图，而是增加Video Conditioning资格层。

### 旧资产处理
- Character / Environment / Prop / Color / Style / Storyboard全部继承原Approval；
- 旧`HD_SHOT_SUPPORT_ANCHOR`若与当前Shot/State完全匹配，可登记为`VIDEO_SHOT_EXECUTION_FRAME`或辅助资产；
- 旧Storyboard Panel / Shot Assembly可经Promotion QC成为Primary Visual；
- 未分类旧资产的`video_usage.primary_visual_eligible`默认FALSE，直到人工/自动迁移确认。

### 旧Workflow处理
`APPROVED_PREVIS_SET`但尚未生成Video的Shot：进入`VIDEO_CONDITIONING_IN_PROGRESS`，只补最小Primary Visual，不重做已批准Storyboard。

已存在真实Approved Video：不因V4.4规则失效。后续需要重生成该Shot时再走新Conditioning Gate。

### Environment
旧Environment Master若含剧情临时人物/破坏状态，不自动废除历史成片；为未来复用地点建立`ENVIRONMENT_CLEAN_CANON`或Clean derivative，并把临时内容迁入World/Scene State。
