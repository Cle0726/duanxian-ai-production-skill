# V4.5.7 Adaptive Video Reference Budget Upgrade

## Goal
Stage 05 separates **Scene Color Authority** from **Direct Scene Color Reference**. The authority remains mandatory; a color-card image slot no longer does.

## Default
A normal scene-bound video defaults to the Approved Shot Execution / First Frame as its direct visual input. If that Primary Visual inherits the current Approved Scene Color Authority and no color-risk trigger exists, use `LINEAGE_ONLY`.

## Modes
- `LINEAGE_ONLY` — default; no extra color-card slot.
- `TEXT_CONTROL` / `TEXT_COLOR_CONTROL` — use when color still needs explicit text reinforcement but a direct image slot is not justified.
- `DIRECT_REFERENCE` / `DIRECT_COLOR_REFERENCE` — only with explicit reason: observed drift, narrative-critical color, multishot color instability, unreliable Primary Visual color, provider requirement, or user requirement.

## Non-negotiable
- `scene_color_authority_id` remains present and current.
- Primary Visual must inherit the same Scene Color Authority.
- Scene-bound images and Shot Execution Frames still Direct Bind the Scene Color Card during the color-baking stage.
- Removing the direct color-card input never removes the final prompt's lighting/color execution text.

## Reference Budget
Priority is P0 Continuity State → P1 Primary Shot Visual → P1 high-risk Identity/Geometry → P2 Color/Style → P3 auxiliary/mood.

The objective is **Minimum Sufficient Reference Set**, not maximum slot occupancy.
