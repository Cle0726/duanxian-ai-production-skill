# V4.5.7 Voice Direction / Prosody Logic Closure

本次升级把原有的Voice Direction / Prosody导演规则从“文档Authority”提升为可机械验证的生产链。

## Canonical Chain

`Actor Performance / Emotional Causality → VOICE_DIRECTION_PLAN → Voice Identity Resolution → voice_direction_prompt_compiler.py → VOICE_PROMPT_HANDOFF → Final Video Prompt → voice_prompt_handoff_lint.py → Approved Video / Picture Lock → voice_tts_handoff_builder.py → VOICE_TTS_HANDOFF → voice_tts_handoff_lint.py → Stage 06 Master`

## What is now structured

每条重要Dialogue / VO会结构化记录：
- Trigger Event / Meaning Appraisal；
- Objective / Tactic / Subtext；
- Affect Label / Arousal / Control；
- Performance Loudness；
- Pace Curve；
- Speech Phrase / Breath Group；
- Pause Map及原因；
- Stress / De-emphasis及原因；
- Pitch / Energy Contour；
- Terminal Intonation及原因；
- Texture Adjustment；
- Listening / Interrupt / Overlap；
- Body-Voice Coupling。

## Hard separation

- Voice Identity = 长期声线身份；Prosody = 当前表演状态。
- Performance Loudness != Mix Loudness。
- Emotion Label不能替代Trigger / Meaning / Objective / Tactic / Subtext。
- Stage 06可以按Picture Lock调整Pause Duration / Phrase Timing，但不能静默改写Voice Identity、Terminal Intonation或其他Approved表演意图。

## No-dialogue behavior

没有Dialogue的Video Unit / Post Unit也显式生成`NOT_REQUIRED` Handoff，不靠“Artifact缺失”猜是否适用。


## Audit hardening

- Plan coverage is now bidirectional: planned lines cannot be undeclared, excluded lines cannot still be planned, and the important-line index must match line importance.
- READY/APPROVED plans cannot contain stale or merely planned lines; pre-video/stage06 lines require shot scope.
- Prompt handoff requires exact per-video-unit line coverage and deterministic compiler fidelity. All explicit pauses, stresses, texture changes, interaction timing, body/voice coupling and landing carryover are surfaced and mechanically checked.
- Stage 06 TTS handoff covers every planned voice-execution line, rejects duplicate/tampered text, preserves texture controls, and requires a Picture Lock fingerprint.


### Stage 03 voice-identity closure

`VOICE_DIRECTION_PLAN_DERIVED` is now a required Stage 02C breakdown gate. Stage 03 Asset Build consumes the plan, and Episode Asset Freeze runs `voice_direction_plan_lint --phase pre_video` against `AUDIO_ASSET_MANIFEST + ASSET_REGISTRY` to produce `REQUIRED_VOICE_IDENTITY_ASSETS_RESOLVED`. This removes the previous ghost gate where the workflow required voice identity resolution without a registered producer.


### Prompt Artifact anti-bypass

`VIDEO_PROMPT_ARTIFACT` can no longer be persisted without an explicit `VOICE_DIRECTION_PLAN + VOICE_PROMPT_HANDOFF`, including no-dialogue units where the handoff is `NOT_REQUIRED`. The artifact now binds the voice plan ID, handoff ID, handoff fingerprint and `voice_handoff_pass=true`; Video Job prompt lint rejects artifacts that omit this proof.
