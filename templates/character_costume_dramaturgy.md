# Character Costume Dramaturgy（人物服装戏剧分析）

> **用途：** Stage 02负责判断“人物为什么今天这样穿”，Stage 03再决定“具体穿什么、怎么搭”。服装是人物行为的一部分，不是每场随机换皮。
>
> **权责：** Director owns WHY; Wardrobe owns WHAT/HOW.

---

## 1｜Stage 02必须先回答

对主要/反复人物的重要Scene，建立轻量`Costume Dramaturgy Brief`：

- `Character`；
- `Core Fashion DNA Ref`；
- `Source Wardrobe Classification Ref`；
- `Dressing Knowledge Boundary`：角色选衣服时已经知道什么，不知道什么；
- `Dressing Motivation`：PROFESSIONAL / CONTROL / ATTRACT / INTIMIDATE / BLEND_IN / DISAPPEAR / IMPRESS / PROTECT / COMFORT / CEREMONIAL / REBELLION / SELF_EXPRESSION / PRACTICAL / HABITUAL / GRIEF_MEMORY / OTHER；
- `Self-Presentation Intent`：今天希望别人看到怎样的自己；
- `Relationship Context`：今天主要会见谁、关系如何影响自我呈现；
- `Costume Narrative Function`：NEUTRAL / STATUS / POWER / VULNERABILITY / ATTRACTION / CONTRAST / BELONGING / ALIENATION / FORESHADOWING / MEMORY；
- `Boldness Intent`：继承角色Boldness，不因“高级/天气”自动降级；
- `Existing LOOK Fit`：YES / PARTIAL / NO；
- `Director Wardrobe Decision`：REUSE / RUNTIME CONFIG / CLOSET RECOMBINE / NEW LOOK；
- `Ensemble Relation`：HARMONIZE / CONTRAST / DOMINATE / ISOLATE / ECHO / NEUTRAL；
- `Critical Costume Read`：当前Scene必须让观众读到的服装信息；
- `Stage 03 Design Requirement`：只写功能/人物/视觉目标，不直接规定未经Approved的具体新裁片。

---

## 2｜Dressing Knowledge Boundary（穿衣知识边界）

角色只能根据“选衣服当时已经知道的信息”做选择。

例如人物在Scene后半才得知死亡消息，不能倒推“她早上穿黑色是因为悲伤”。后续事件只能改变Runtime State：外套脱下、袖子卷起、衣服淋湿、沾血、饰品摘掉等。

违反时：`COSTUME_HINDSIGHT_CONTAMINATION_FAIL`。

---

## 3｜Existing LOOK Fit Routing

### YES
当前Approved LOOK已经同时满足人物、场合、功能与戏剧需求 → REUSE。

### PARTIAL
先尝试：
1. Runtime Configuration；
2. Closet Recombine；
3. 最小新Item。

不能因为“想更新鲜”直接做整套新皮肤。

### NO
只有现有Closet确实无法满足当前人物/场合/剧情/视觉需求时，才允许NEW LOOK。

---

## 4｜Director不得越权设计服装

Stage 02可以说：
- 需要更强控制感；
- 今天有意识提升吸引力；
- 需要与另一人物形成视觉对立；
- 需要让腰腿比例在Full Body里成为读点；
- 需要一件适合雨夜步行的外层。

Stage 02不能凭空锁：
- “必须某个具体陌生领口”；
- “必须一件尚未设计的特殊夹克”；
- “必须某条具体花纹”。

这些属于Stage 03 Wardrobe Authority。

---

## 5｜Camera × Costume Readability

如果`Critical Costume Read`承担人物/剧情信息，Director必须确认镜头真的能读到。

例如：
- POWER依赖肩腰结构 → 至少有能读出上身结构的景别；
- MEMORY依赖Signature Item → 关键Beat需要可读；
- ATTRACTION依赖腿部比例 → 全程CU不可能完成这一表达。

Stage 03正式Look批准后做`DIRECTOR COSTUME READABILITY CHECK`：
- Look设计错误 → Stage 03最小修订；
- Look正确但镜头根本读不到关键设计 → Stage 02最小Patch；
- 非关键小细节不可见 → 不返工。

最终状态：`COSTUME_DRAMATURGY_RECONCILED`。

---

## 6｜Ensemble Relation不等于服装配额

HARMONIZE / CONTRAST / DOMINATE / ISOLATE / ECHO描述戏剧关系，不要求机械换品类、换综合色或凑Boldness档位。

两个人都可以穿裤装、西装或长外套，只要其Fashion DNA、比例、穿法、材质、身体呈现与人物关系仍然清楚。

---

## 7｜Stage 03 Handoff

Stage 03读取：
`Costume Dramaturgy Brief + Source Wardrobe Classification + Character Fashion DNA + Closet + Body Identity/Presentation Authority + Environment + Wardrobe Diversity`

再决定具体：
- Item组合；
- Category；
- Cut；
- Material；
- Color；
- Hosiery；
- Personal Adornment；
- Body Presentation Mode；
- LOOK Selection Provenance。
