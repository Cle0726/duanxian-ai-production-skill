# 导演拆解模板 Visual-First Director Intelligence + Architecture

> **Input Authority：** 只从当前`EPISODE SCREENPLAY LOCK`进入导演拆解；未锁定的小说段落/Story Lock不能直接拆Shot。
本模板用于 **Stage 02（导演拆解）**。Stage 02的职责不是只把剧本切成Shot和资产清单，而是先完成真正的导演决策：**戏剧空间、人物距离、前中后景、轴线/视线、画面主次、镜头推进、运镜意图与剪辑动机**。

正式顺序：

**EPISODE SCREENPLAY LOCK → Scene Intent → World State → Audience State + Felt Intent → Directorial Importance Tier → Directorial Interpretation Candidates → Department Critique → Director Judge → Sequence Arc → Editorial Viewpoint/Cut Intent Draft → Scene Spatial Requirement Draft → Actor / Combat / Crowd → Dramatic Geometry / Blocking → Axis / Screen Direction / Eyeline → Distance Arc / Depth → Cinematography Grammar → Scene Coverage Strategy / Shot Progression → Editorial Plan + Detailed Shot Contract Lock → DIRECTOR CORE LOCKED → Director→AI Execution Translation → Segment → Previsualization Strategy → Raw Coverage / Video Risk / Shot Assembly / Character Requirement → Asset Consolidation & Sufficiency Audit → Final Episode Asset Manifest → DIRECTOR BREAKDOWN READY → Stage 03 → Director Spatial Reconciliation → Freeze → Stage 04。**

导演智能层必须读取`director_intelligence_core.md` + `directorial_department_critique.md` + `sequence_arc_engine.md`；剪辑设计读取`editorial_grammar_engine.md`，先建立Editorial Intent Draft，Shot Progression完成后再锁`EDITORIAL_PLAN`；导演架构层读取 `director_architecture_engine.md` + `cinematic_spatial_staging_engine.md`；AI执行翻译读取`director_to_ai_execution_boundary.md`。首次/关键变身同时读取 `transformation_splendor_architecture.md`。新Environment在Stage 02只锁功能空间需求，真实几何由Stage 03批准后通过 `director_spatial_reconciliation_gate.md` 复核。

### Editorial Plan / Cut Motivation
先按`editorial_grammar_engine.md`建立Sequence级`Viewpoint Arc`。每个真实Cut至少锁`Edit Function + Cut Trigger + Cut Timing + Transition + Continuity Strategy`，并回指最直接`Shot Relation`。无CUT写CONTINUOUS_HOLD。

没有值得切换的信息/权力/动作/空间/观看关系变化时，优先保持原Shot；禁止机械一句台词一反打一切。默认通过多个Formal Shots分别生成，再在Stage 06按Editorial Plan组接。

### Visual Hierarchy / Critical Read
`Focus Owner`是第一眼主体；`Critical Visual Read`是这个镜头必须真的让观众看清的字段。若要求看清TE-03眼妆、关键伤口、Weapon Contact，却选择让它在安全远景里不可辨识，Stage 02即判失败，不把问题推给Storyboard。

### Depth / Crop
重要多人Shot允许并鼓励合法FG/MG/BG错层、部分遮挡与裁切。除非刻意仪式性陈列，禁止默认“所有人同深度、相似大小、均匀间距、全身完整”。

- 人物必须明确落在病床、驾驶位、后排、台阶、舞台、门区、柜台等功能位置；
- 当前镜头必须同时读到人物 + 场景 + 关键道具/实体；
- Montage一次性情境镜头：不值得给每个路人做完整Character Master，但直接做一张高质量情境组装资产能显著降低Video风险；
- 已有Master/Coverage理论上能推断，但Video仍会大量猜“怎么把它们放在一起”。

### NO / 其他Owner
- 只缺结构面/反方向 → Coverage；
- 只缺持续伤势/破损 → Persistent State；
- 只缺局部递交/扶抱/压伤/机关细节 → Production Support；
- 只缺精确Camera / Blocking / Panel节奏 → Stage 04 Storyboard；
- 必须等Approved Storyboard以后才能唯一确定的高清镜头组合 → Stage 04 Video Conditioning Frame。

## 时长方法

> 本阶段必须读取`video_generation_duration_authority.md`。整集Runtime Target与单次视频生成能力是两套不同字段：**Director Target由导演自然判读；Skill不设置固定Generation Segment秒数上限。当前平台若有Slot / Hard Max，只能在Director Judge后的Execution Translation读取。**
- 先选定15–18分钟区间内的具体目标，再拆Scene/Beat/Shot。
- Scene预算之和应≈本集目标；Beat预算之和应≈所属Scene；Shot预算之和应≈所属Beat。
- Shot预计成片时长必须容纳真实对白/VO语流、真正有因的停顿、听者反应和情绪落点；普通生理呼吸融入语流，不为每个句号单独预留“呼吸Beat”。
- `Director Target Duration`先按Beat完成、Dialogue/VO、Actor Performance、Action Physics、Camera Travel与Meaningful Hold决定；采用“完成叙事所需的最短自然时长”。`Model Reliability / Platform Duration Profile`只能在Target锁定后影响**如何执行**，不得反向缩短或拉长Director Target，也不得把平台Slot反写成导演目标。
- Skill不因自然执行超过固定秒数而自动拆分。只有当前可靠Platform Duration Profile存在Hard Max且无法容纳Target时，才在最自然的Beat/CUT/Thought/Action Landing处拆成多个Segment；禁止压缩对白/表演，也禁止为了填平台时长增加Dead Hold。
- 不要把自然需要7秒说完的台词硬塞进4秒镜头。
- 超过18分钟：优先压缩重复信息、合并低价值镜头、移动次要Beat或拆集，不机械加速所有镜头。
- 低于13分钟：优先补足必要反应、空间建立、因果过渡和情绪铺垫，不用空镜或慢动作硬拖。

## Asset Consolidation & Sufficiency Audit

- 按Authority Owner / Parent / Visual State / Environment View / Core Blocking Relation / Critical Fields跨Shot聚类；

- 必须等Approved Storyboard才能唯一确定的组合只登记Stage 04 Video Conditioning Plan；
- 反向逐Shot执行Sufficiency Check，确保静态可解决的Critical Risk都有Final Asset ID覆盖。

必须输出`Episode Asset Accounting`：Raw Demand Nodes / Reuse / Merge / Non-Static Removed / Stage 04 Deferred / Stage 03 New Unique Assets / Projected Stage 03 Freeze Pool / Projected Final Episode Static Pool，并按资产类别统计。**数量只用于解释和异常Review，不设置15–18分钟固定图片配额。**

未运行标`ASSET_CONSOLIDATION_NOT_RUN`；真实静态缺口标`ASSET_SUFFICIENCY_GAP`；确认无理由重复建设标`ASSET_REQUIREMENT_DUPLICATION_CONFLICT`。
