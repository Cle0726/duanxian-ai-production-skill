# Wardrobe Diversity Design Matrix（服装多样性与个人穿衣身份矩阵）

> **用途：** 保证《断弦之歌》角色共享同一时代和世界质感，但不会全部穿成“同一家品牌、同一种法式长外套、同一比例换颜色”。本矩阵补充`wardrobe_style_design_engine.md`，不替代Character Closet。

## 1｜统一的是世界，不是模板

共享：
- 20世纪70–90年代欧洲都市/地区现实基础；
- 可穿、可行动、符合职业/阶层/天气；
- 成熟二维插画材质语言；
- 当前Global/Scene Color DNA。

允许并鼓励差异：
- 法式都市极简；
- 中欧实用剪裁；
- 北方功能型；
- 南欧柔软层叠；
- 工匠/驾驶员/医护/学生/知识分子/旧贵族残余/流浪艺术家等不同生活系统；
- 个体偏保守、精确、浪漫、粗粝、随性、制服化、旧物复用等。

**French-inspired Urban Minimalism只是可用的一种子语言，不再是所有角色的统一制服。**

## 2｜Wardrobe Identity Axes（服装身份轴）

每个主要/反复角色至少定义：

1. `Wardrobe Archetype`｜个人穿衣原型
2. `Silhouette Family`｜修长纵向 / 短上衣长腿 / 宽肩窄腰 / 柔和A线 / 直身功能型 / 层叠垂坠等
3. `Proportion Rhythm`｜上短下长、上长下窄、腰线高低、外套/裙/裤长度关系
4. `Shoulder Language`｜自然肩 / 结构肩 / 落肩 / 窄肩强调
5. `Collar / Neckline Language`｜开放、封闭、翻领、圆领、窄V、衬衫领、围巾主导等
6. `Waist Treatment`｜收腰 / 直身 / 腰带 / 高腰 / 低存在感
7. `Layer Density`｜1层极简 / 2–3层秩序 / 松散多层
8. `Bottom / Hem Language`｜裤型、裙长、开衩、衣摆节奏
9. `Material Mix`｜羊毛/皮革/针织/棉/丝/工装布等比例
10. `Footwear Language`｜短靴、长靴、皮鞋、实用鞋等
11. `Accessory / Adornment Strategy`｜读取`personal_adornment_identity_system.md`：SIGNATURE / ROTATING / FUNCTIONAL / MINIMAL / INTENTIONAL_NONE；默认不允许把“极少”误执行成全员空白
12. `Maintenance / Wear`｜精心保养 / 修补使用 / 工作磨损 / 随意但干净
13. `Styling Habit`｜卷袖、扣紧、敞领、围巾打法、裤脚、手套、发饰与衣物关系
14. `Hosiery Language`｜连裤袜/丝袜颜色与厚度习惯：黑色系/白色系/深色系 × 透明/半透明/不透；禁止全员同色同厚度
15. `Category Family`｜`Dominant Family + Justified Alternatives`：记录长期偏好，不要求跨Scene机械轮换
16. `Signature Contrast`｜一个不破坏世界观的个人反差，例如精确制服感配旧皮手套、浪漫裙装配实用男式外套等
17. `Body Presentation Preference`｜角色常见DIRECT / FRAMED / PROPORTIONAL / IMPLIED / CONTRAST倾向；只是偏好，不锁死每套LOOK
18. `Forbidden Template`｜绝不能滑向的项目常见模板

## 3｜同Scene Ensemble Diversity（同场群像服装差异）

同Scene主要角色并排时检查：
- 是否都穿相近长度深色长外套；
- 是否都用同一高领/围巾封闭领口；
- 是否都靠同一收腰方式；
- 是否上下装比例完全一致；
- 是否所有女性都是裙+靴，所有男性都是长裤+大衣；
- 是否只是“同品类”但实际Styling Grammar完全不同；同为裙装/裤装/西装不构成自动冲突，只有比例、肩线、领口、腰位、层次、材质、身体呈现和穿法也高度相似才需要调整；
- 是否连裤袜/丝袜全员同色（全员黑丝/全员白丝均属撞型）；
- 是否材质都集中成羊毛/黑皮，没有职业与生活差异；
- 是否鞋靴、手部、配饰缺乏个人习惯；
- 是否主要角色全都什么也不戴，或反过来都戴同一种细链/耳环模板。

若只改变颜色仍像同一品牌Lookbook，判：
`WARDROBE TEMPLATE COLLISION`。

## 4｜Diversity不等于无限新衣服

多样性优先来自：
- 不同人物拥有不同Closet；
- 同一Closet内有不同组合；
- 比例与穿法变化；
- 职业/阶层/活动差异；
- 材质和维护状态差异。

不是每Scene凭空发明新衣服。

## 4.1｜Style-Family Diversity（风格家族差异）

群像比较时增加`Style Family`轴。允许不同角色明显落在不同服装子语言，只要共享同一世界的绘画、时代与材质可信度。

对圣谱者Transformation尤其如此：Dark Gothic / Gothic Romance只是可选家族之一；Opera Couture、Avant-garde、Art Deco、Ballet-derived、Ceremonial、Military Deconstruction、Mythic、Minimal Monumental、Glam、Instrument-Architecture等都可成立。

如果主要圣谱者因为“成熟、神秘、高级”全部收敛为暗色哥特/长裙/束腰/旧金，直接判`STYLE_FAMILY_DEFAULT_COLLAPSE`，不能只换综合色解决。

## 5｜Transformation Costume Diversity

圣谱者礼服同样执行本矩阵，但“Wardrobe Archetype”替换为`Transformation Costume Grammar`：
- Dress / Coat / Split-Skirt / Trouser / Bodice / Bikini-Top / Armor-soft / Draped / Tailored等结构族；
- 肩、腰、腿、背部开放与封闭关系必须不同；
- 衣摆数量、长度、重心、对称/不对称方式不同；
- 不能所有女性都是收腰短裙+长靴，也不能所有男性都是长外套+高领；
- Music Identity决定结构节奏，不是只换主色和纹样。
- 角色可使用更大胆的Style Family / Body-Line / Negative Space / Material Contrast；“成熟高级”不是收敛到暗色哥特的理由。

## 6｜QC最低条件

- 遮住头部后，主要角色仍能从服装剪影和比例大致区分；
- 同Scene不设置固定“凑够N项差异”配额；综合比较`Silhouette / Proportion / Collar / Layer / Material / Footwear / Body Presentation / Styling Habit`后，只要整体`Styling Signature`清楚区分即可。只有多维同时高度重合、远看像同一套Look模板时才判撞型；
- 主要/反复角色已完成Adornment Opportunity Review；群像不能因为“克制”默认全员空白；
- 差异来自角色生活与人格，不是随机时装秀；
- 综合色可以属于同一Scene，但服装结构不能因此收敛；
- 复用Closet仍然保留人物个人穿法。
