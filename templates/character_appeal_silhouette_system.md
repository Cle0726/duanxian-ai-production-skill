# Character Appeal & Silhouette System（角色魅力与剪影系统）

> **用途：** 给《断弦之歌》的正式人物与圣谱者变身设计增加“网络时代第一眼吸引力”的正向设计规则。它不是低俗化指令，也不是单纯要求更多裸露，而是要求角色必须拥有**清楚、独特、可传播的魅力焦点（Appeal Hook）**与**一眼可认的剪影（Silhouette Hook）**。

## 1｜核心原则

- **Attractiveness is a design requirement, not an accidental by-product.**（角色吸引力是正式设计目标，也是可传播的商业指标，不是设定正确后的偶然结果。）
- 成年角色的**脸、发型、肩颈、胸背、腰线、腿线、手部、衣摆与武器姿态**等视觉吸引点必须被主动设计并突出呈现；身材比例可按短剧流量审美做理想化设计：女性允许明显的胸腰臀曲线、长腿与窈窕比例，男性允许宽肩窄腰、清晰胸背肩腹线条。
- 角色魅力与世界观、人格、音乐身份、功能性必须一致；大胆、性感、有传播力的设计被明确允许，底线只有一条：不与《断弦之歌》世界观、人物人格与项目统一画风直接冲突。
- **男女通用。** 女性不默认“短裙+大腿”，男性不默认“高领+长外套全包死”；同时理想化身材不等于全员同一副身材，项目内需要区分身材类型（丰满/窈窕/高挑/健美等）。
- 除非人物设定明确要求封闭、禁欲、监察、人工秩序、病态保护或其他剧情原因，否则**成年角色不应默认全包保守化**。
- **气质方向放开：** 成年角色的整体气质允许成熟妩媚、冷艳、飒爽、慵懒、攻击性吸引力等方向，清纯/保守不再是默认选项；气质必须与人格、Music Identity与世界观一致，并与Appeal Hook互相支撑；未成年角色不使用成人性感化规则，但仍允许冷静、坚毅、叛逆、阴郁、古怪、清爽、可爱等完整非性化人格范围；不得因为“非成人性感”而模板化成同一种清纯/可爱气质。
- **开放是人格的设计结果，不是项目默认：** 每个角色的开放程度（`Boldness Dial`）必须先由其性格、身份、职业、阶层与剧情位置推导，再决定暴露几何与贴身剪裁；禁止因为“项目要求大胆”就把全员拉满——禁欲系、克制系、朴素系本身可以是角色标志，全员开放时克制角色反而最显眼。
- **群像Boldness反模板：** `Boldness Dial`首先服从每个角色自己的性格/身份/职业与已批准Authority，不按Scene机械凑档位。只有系统无人物依据地把原本不同角色全部推向同一种BOLD/EDITORIAL安全公式时，判`BOLDNESS DISTRIBUTION COLLAPSE`；不能为了“拉开档位”擅自降低或抬高已成立角色。
- **对比度价值：** 开放冲击力来自对比——大胆角色的暴露几何在克制群像中才有第一眼杀伤力；全员开放=全员平庸，流量钩子互相抵消。适度保守角色是流量资产的组成部分，不是保守主义残余。

## 2｜八个设计字段

每个正式人物（尤其是圣谱者变身礼服）至少要回答：

1. `Primary Appeal Hook`｜主要魅力焦点
   - 例：锁骨肩颈、背部、腰线、腿线、手臂/前臂、手套与长指、胸肩比例、长腿、靴线、脸部/眼神、发型/发丝轮廓。
   - 发型可以成为角色的第一眼卖点（详见 `hair_identity_architecture.md`）。

2. `Secondary Appeal Hook`｜次级魅力焦点
   - 只能辅助，不能和Primary互相抢戏。

3. `Exposure Geometry`｜开放区域形状
   - 例：宽领、窄V、单肩、不对称露肩、背部U形、侧腰切口、高开衩、前短后长、前臂暴露。
   - 写“露肩/露腿”不够，必须说明**开口几何**。

4. `Body-Line Emphasis`｜身体魅力重点（**硬性必答**，成年角色不得空缺；它定义“哪些身体特征值得被感知”，不规定每套衣服必须用贴身/收腰方式直接描线）
   - 例：肩—腰—腿比例、胸腰臀曲线、胸背厚度、收腰、臀线、腿部重心、腿身比、颈部长度、前臂线条、腹背肌肉线条。
   - 成年角色的身体线条与身材比例按短剧流量审美理想化设计；**描述必须落到具体生理维度**：女性允许明确写出丰满胸型体积感、纤细腰、圆润臀腿线、饱满大腿与小腿线条、长腿比例等；男性允许明确写出宽肩、胸肌轮廓、窄腰、腹肌分区线条、结实前臂与腿部线条等；不同角色身材类型需区分，禁止全员同一副“完美身材”。
   - **身材描述必须写入Prompt的IDENTITY高权重段**，不能只停留在设定文档里；生成时若身材被弱化/筒化，按 `BODY_IDENTITY_DRIFT / BODY_BEAUTY_SUPPRESSED` 处理并重试。
   - 具体服装如何呈现这些身体魅力，读取`body_identity_presentation_authority.md`；Body Identity属于人物Canon，Body Presentation属于当前LOOK，禁止把“人物身材美”机械翻译成每层收腰/贴身/高腰。

5. `Silhouette Hook`｜剪影识别点
   - 例：单侧长尾、前短后长裙片、收腰长外套、外套+内层裙片、高开衩长裙、肩部大轮廓、窄腰长腿、特殊武器负形。

6. `Motion Appeal`｜动态魅力点
   - 例：转身时露背、抬臂时肩线、横移时腿线、举武器时前臂、落地时衣摆与靴线。

7. `Forbidden Generic Pattern`｜禁止套用的通用模板
   - 防止全员撞型。
   - 例：所有女性都短裙黑丝高跟；所有男性都高领长外套全覆盖；所有角色都靠露大腿吸引。

8. `Boldness Dial`｜大胆度
   - RESTRAINED / ASSERTIVE / BOLD / EDITORIAL；成年角色必答。
   - 它决定整体视觉进攻性，不等于裸露面积。

## 2.1｜Adult Design Boldness Authority（成年角色大胆设计权限）

成年角色的魅力设计允许主动选择：`RESTRAINED / ASSERTIVE / BOLD / EDITORIAL`。这不是单纯“裸露等级”，而是整体视觉决定的进攻性：身体比例、贴身程度、开放区域、轮廓夸张、综合色焦点、材质与姿态都可参与。

- **ASSERTIVE**：身体线条明确、剪影有攻击性、开放区域不回避；
- **BOLD**：允许大面积Exposure Geometry、极端收腰/肩胯/长腿比例、强不对称、明显透视/镂空/开衩、强烈Fashion Silhouette；
- **EDITORIAL**：允许“奇怪但漂亮”的高定式比例与大图形，只要角色/世界观/动作需求仍成立；
- “成熟 / 高级 / 克制”不得自动把Boldness Dial降级；其中“克制”只约束**无层级堆砌**，不约束身体线条、综合色强度或设计野心；
- 角色之间仍必须有不同身体类型与不同性感方式，禁止把大胆理解成统一流量模板。

如果任务已明确`BOLD / EDITORIAL`，生成结果却自动回到高领、长袖、暗色全包、宽松吞身材的安全答案，标记`APPEAL_BOLDNESS_SUPPRESSED`并返回Stage 03。

## 3｜女性角色指导

- 优先从**肩颈、锁骨、背部、腰线、腿线**中选择1个Primary Hook；发型/发丝轮廓也可作为Hook。
- 允许全身同时大面积暴露，但必须有1个最核心的Primary Hook与清楚的剪影，避免“无焦点堆暴露”。
- 性感是正式设计语言：允许主动、明确、有设计感的大面积暴露几何与身体线条展示，而非被动的“多露一点”。
- 可用：不对称露肩、宽领、深V、胸口开洞、束身结构、局部露背、侧腰结构、高开衩、前短后长裙片、透视纱、黑丝长靴、镂空、长靴腿线等；使用哪类结构由角色人格与Music Identity决定，禁止全员套同一模板。

## 4｜男性角色指导

- 男性魅力可来自**肩颈、胸背、窄腰、长腿、前臂、手套/长指、衣摆与武器姿态**；允许宽肩窄腰、清晰肌肉线条的理想化身材设计。
- 可用：微开领、窄V、深开领、开襟、颈侧暴露、局部露胸、前臂暴露、清晰肩线、收腰长外套、修身内层、长靴线条。
- 禁止把所有男性都做成：高领封死 + 长外套 + 毫无身体线条。
- 允许贴身剪裁与开襟设计呈现胸背肩腹线条，但不得全员同一“肌肉模板”，身材类型仍需区分。

## 4.1｜与服装多样性协同

Appeal Hook不能强迫所有角色穿成同一种性感/优雅模板。日常服装同时读取`wardrobe_diversity_design_matrix.md`，变身礼服同时做Costume Grammar横向比较。

## 5｜唯一性要求

- 同一项目中，角色的魅力来源不能高度重复。
- 如果两个角色都被描述为“短裙、露大腿、露肩、黑金礼服”，就需要进一步区分：谁靠肩颈、谁靠背部、谁靠腿线、谁靠腰线、谁靠武器姿态。
- **不同人物的魅力钩子必须和其人格 / 音乐身份一起成立。**

## 6｜QC判定

以下情况直接判定 `APPEAL DESIGN WEAK`：
- 成年角色在没有明确剧情理由时全身包死，没有任何明确魅力焦点；
- 角色魅力只剩“脸好看”，服装与剪影没有帮助放大人物吸引力；
- 女性角色全部收敛成同一套保守黑礼服；
- 男性角色全部收敛成高领长外套无差别模板；
- 与其他人物相比存在明显的模板重复（同一暴露模板/同一身材模板）；
- 为了“性感”切换到另一套画风/渲染风格，破坏《断弦之歌》统一二维插画。

以下情况判定 `TRAFFIC APPEAL WEAK`（流量吸引力不足）：
- 成年主要角色缩到手机封面/缩略图没有可传播的第一眼卖点（脸、身材、发型、剪影、暴露几何至少其一不成立）；
- `Body-Line Emphasis`空缺，或Body Identity / Appeal Hook在当前Look中被无理由抹掉；宽松/Oversized本身不构成失败，按`body_identity_presentation_authority.md`判断整体Body Beauty是否成立；
- 人物魅力与同类型短剧/漫剧头部角色相比明显缺乏记忆点。

通过标准：
- 一眼能看出人物魅力中心；
- 缩到手机屏幕依然读得出剪影与吸引点；
- 角色魅力和功能性、世界观、音乐身份一致；
- 与其他人物相比不存在明显的模板重复；
- 成年主要角色具备可传播的第一眼流量钩子。
