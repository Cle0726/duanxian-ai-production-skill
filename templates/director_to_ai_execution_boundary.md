# Director → AI Execution Boundary（导演到AI执行边界） Current Authority

> **用途：** 保护导演决策不被模型能力、Reference槽位、免费额度、已有资产、真实Approved Geography或Prompt习惯静默反向改写。

## 1｜两层契约

### Director Invariants
来自Director Judge / Sequence Arc：
- Audience Alignment；
- Reveal / Withhold顺序；
- 核心Blocking / Distance变化；
- POV / Perspective原则；
- Detailed Shot Contract中明确标为叙事因果的Entry/Landing Camera Geometry、Lens Family、Focus Strategy、Stabilization或Shot Relation；
- 关键Hold / Cut；
- Reaction Give / Deny；
- Opening / Closing Image Function；
- 其他Non-Negotiable Directorial Invariants。

### Execution Variables
生产层可以优化：
- Segment拆分；
- 当前平台Duration Profile / Slot / Hard Max（仅已验证时）；
- Reference Pack；
- Coverage / Support / Assembly / FMH / Anchor；
- Prompt结构；
- 同一动作的执行分段；
- Crop / Control Image / TEXT_CONTROL等输入方式。

## 2｜Conflict Protocol

执行现实包括：AI模型/平台能力、Reference容量、Approved Geography、已批准资产结构与真实可拍空间。它们都只能在Selected Director Plan之后提出约束。

当执行层发现Selected Plan无法稳定实现：

```text
AI_EXECUTION_CONSTRAINT_CONFLICT / DIRECTOR_INVARIANT_SPATIAL_CONFLICT
Affected Director Invariant：
Execution / Reality Limitation：
Attempted Non-Destructive Solutions：
Remaining Conflict：
Options for Explicit Director Compromise：A / B / C
```

必须回Director Judge选择。不能自行换成“最稳的普通镜头”。

### Compromise Propagation
Director Judge批准妥协后：
1. 更新Selected Option / Accepted Compromise / Non-Negotiable Directorial Invariants；
2. 只要Audience Alignment / Reveal / Blocking / POV / Reaction Give-Deny / Key Hold-Cut / Opening-Closing Function任一改变，重跑受影响`Sequence Arc`；
3. 再重算受影响Detailed Shot Contract；
4. 通过Change Impact只更新受影响Segment / Previs / Coverage / Assembly / Support / Prompt；
5. 未受影响资产与已批准历史结果保持有效。

不得只改Stage 04/05 Prompt而留下旧Decision Card / Sequence Arc继续标LOCKED。

## 3｜Hard Fail
- `AI_CONSTRAINT_BACKDRIVE_FAIL`：先看模型/资产/成本限制再选导演方案；
- `DIRECTOR_PREMATURE_PRODUCTION_CONTEXT_FAIL`：Director Judge前的Option/选择理由被已有资产、Reference、Slot或成本信息污染；
- `DIRECTOR_INVARIANT_SILENT_DRIFT`：生产翻译静默改变导演核心；
- `EXECUTION_COMPROMISE_UNJUDGED`：需要艺术妥协但没有回Director Judge；
- `DIRECTOR_COMPROMISE_PROPAGATION_GAP`：Judge已批准妥协，但Decision Card / Sequence / Shot Contract没有同步更新。
