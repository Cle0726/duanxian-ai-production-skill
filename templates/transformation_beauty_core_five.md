# Transformation Beauty Core Five（圣谱者变身美术五核心）

> **用途：** 定义《断弦之歌》圣谱者变身最优先、最值得投入美术资源的五个视觉核心。所有谱线、饰品、材质页、圣约指挥棒与Transformation FX都应服务这五项，而不是喧宾夺主。

## 1｜总纲

**Transformation Beauty Core Five：**
1. `Costume`｜礼服
2. `Eye Makeup`｜眼影 / 眼周纹样
3. `Hair`｜头发
4. `Pupil / Iris`｜瞳孔 / 虹膜结构
5. `Music Weapon`｜音乐武器

核心分工：
- **礼服 = 惊艳 / Silhouette Impact**
- **眼影 = 精致 / Facial Artistry**
- **头发 = 气场 / Motion & Aura**
- **瞳孔 = 身份 / Identity Signature**
- **音乐武器 = 音乐与战斗 / Music Identity Embodiment**

## 2｜Beauty Priority 与 Identity Priority

### Beauty Priority（审美冲击优先级）
通常先看：
**礼服 → 眼影 → 头发 → 瞳孔 → 武器与全身关系。**

### Identity Priority（角色识别优先级）
通常先锁：
**瞳孔 → 眼影/眼周 → 头发 → 礼服 → 音乐武器。**

两套优先级不矛盾：礼服负责第一眼大面积冲击，瞳孔负责近景唯一身份。

## 3｜五核心必须共享同一个 Music Identity

五核心不得各自独立“做漂亮”。必须从同一套 `Music Identity / Visual Grammar（音乐身份 / 视觉语法）`推出：
- 节奏是锐利还是连贯；
- 力量是爆发、承重、回忆、悲怆、舞蹈、机械、宗教性还是其他剧情支持方向；
- 线条是切分、弧线、重复、断裂、回环、下沉、上扬；
- 材质是旧金属、谱墨、丝绒、弦线、木质乐器、玻璃/瓷裂等；
- 对称性、层次与运动节奏是否一致。

## 3.1｜Transformation Splendor Architecture（华丽度架构）

五核心除共享Music Identity外，首次/核心变身必须读取`transformation_splendor_architecture.md`。设计顺序改为：`Costume Thesis → 2–3 Hero Decisions → Graphic Block / Negative Space → Large/Medium/Small Splendor → Material Contrast → Focal Chroma/Light`。

**当前项目明确允许更大胆的性感权限、成人身体线条、极端时装比例、强综合色块与强材质反差。** Boldness必须角色专属，但不得因为“成熟/高级/克制”自动被系统削弱。

如果缩成缩略图后，变身角色主要只剩“普通暗色衣服 + 更多金线/裙片”，判`TRANSFORMATION_SPLENDOR_FLAT_FAIL`。

## 4｜Costume（礼服）

礼服先建立`Transformation Costume Thesis`，再锁：
1. `Primary Costume Signature`｜最大图标决定；
2. `Secondary Costume Signature`｜第二记忆点；
3. `Tertiary Accent`｜0–1。

随后才用Splendor Architecture支持它：
- Graphic Block / Character Color Geometry；
- Negative Space Architecture；
- Large / Medium / Small层级；
- Material Contrast；
- Body-Line / Exposure Geometry；
- Weapon-Body Silhouette；
- Music Identity Structural Translation。

Dark Gothic只是可选Style Family，不具默认优先级。允许Opera / Couture / Avant-garde / Art Deco / Ballet / Ceremonial / Mythic / Military Deconstruction / Glam / Minimal Monumental / Instrument Architecture等角色专属方向。

成年角色可使用`RESTRAINED / ASSERTIVE / BOLD / EDITORIAL`不同Boldness Dial。性感、身体线条、贴身、透视、开洞、深V、高开衩、极端比例均是正式设计语言；不需要为了“高级”自动收回，但不能让所有角色复制同一暴露模板。

不得用“堆蕾丝、堆宝石、换主色”代替真正的Hero Signature；也不得把“避免堆砌”误读成禁止蕾丝、珠宝、华丽头饰或大型装饰本身——只要它们在主次结构中有职责，就可以大胆使用。

## 5｜Eye Makeup / Graphic Eye（眼妆与图形化眼部）

正式读取`musical_eye_motif_system.md`，设计优先级只有三层：
1. `Primary Eye Signature`｜唯一主记忆点；
2. `Secondary Graphic Signature`｜MAIN/CORE必填；
3. `Periocular Emblem`｜0–1个Accent。

其他Eyeshadow / Eyeliner / Lash / Finish / Symmetry / Side View字段全部降为Supporting Fields，职责是稳定复现这2–3个强决定，不要求每个字段都单独炫技。

音乐来源可以是：
- LITERAL_NOTATION；
- DERIVED_MUSICAL_GLYPH；
- MUSICAL_GEOMETRY。

**不再强迫每个人脸上都保留一个教科书式Notation Anchor。** 但`Musical Origin Trace`必须成立：如果眼部删除文字说明后只是普通幻想妆，仍判失败。

Eye Makeup Presence只能MINIMAL / STANDARD / EXPRESSIVE，禁止NONE / ABSENT。男性或极克制角色可以MINIMAL，但仍需要Graphic Eye Layer。

禁止：
- 普通眼妆 + 换角色色；
- 普通眼妆 + 眼尾贴♪；
- 每个字段都做一个独立符号导致眼部过度设计；
- 不同角色只靠Periocular小点或颜色区别；
- 侧脸失去Primary Graphic。

详细碰撞读取`eye_signature_ledger.md`与`musical_eye_motif_registry.md`。

## 6｜Hair（头发）

变身头发承担气场、运动与吸引力，但必须先读取`hair_identity_architecture.md`：
- Hair Splendor Upgrade必须参与Large/Medium Silhouette，而不是只做发梢渐变；
- 保留日常Hair ID的发际线、Face-framing、后发核心轮廓；
- 通过发束重组、束点变化、发饰、渐变范围、边界形态和运动重量体现音乐人格；
- 不能所有角色都使用“长发舒展 + 发梢渐变 + 飘带”；
- 即使遮掉综合色和发饰，也应能从变身发型轮廓认出原角色。

## 7｜Pupil / Iris（瞳孔 / 虹膜）

瞳孔是身份签名。必须：
- Core Pupil Symbol角色唯一；
- Iris Topology角色唯一；
- 近景真实可读；
- 像刻在虹膜内部，不是LED贴纸；
- 与Music Identity有关，但不能只是把一个普通音符贴进去。

## 8｜Music Weapon（音乐武器）

音乐武器不是普通武器贴音符，也不是把真实乐器粗暴加刀刃。

它必须把至少三类信息转译为可战斗结构：
1. **Instrument / Voice Logic**：乐器或声部的轮廓、发声/演奏结构；
2. **Performance Gesture**：拉、拨、击、吹、按键、挥拍、指挥等动作逻辑；
3. **Combat Function**：刺、斩、盾、射击、缠绕、冲击、控制、支援等可执行功能。

设计时问：
> 如果遮掉音符装饰，只看轮廓、握持方式与动作，这把武器是否仍然能让人感觉它属于这个角色的音乐身份？

如果答案是否定的，判定 `MUSIC WEAPON GENERIC`。

## 9｜Supporting Layer（辅助层）

以下内容是第二层，必须服务五核心：
- 发饰；
- 鞋靴；
- 暗纹 / 谱线；
- 局部金属；
- TM-01材质页；
- Accord Baton；
- Transformation FX。

不得让满屏特效遮住脸、礼服轮廓、头发或武器结构。

## 10｜Core Five QC

- [ ] 五核心都能用一句话说明其角色专属设计，不是“漂亮/酷”这种泛词；
- [ ] 五核心来自同一个Music Identity，不是五套拼贴风格；
- [ ] 礼服先有Costume Thesis与2–3个Hero Decisions；Dark Gothic没有被当作默认高级答案；
- [ ] Graphic Block / Negative Space / Material Contrast在去掉小纹样后仍成立；成年Boldness没有被无理由压平；
- [ ] 眼部Primary Eye Signature清楚，MAIN/CORE Secondary Graphic成立，Periocular最多0–1；不是字段平均用力或同款换色；
- [ ] 头发继承Normal Hair ID，并拥有角色专属轮廓、发束重组、渐变/饰件与动态逻辑；
- [ ] 瞳孔在近景真实可读且不撞型；
- [ ] 音乐武器具有音乐结构 + 演奏动作 + 战斗功能，不是普通武器贴音符；
- [ ] Supporting Layer没有压过五核心。


## Splendor Hard Gate
- Costume Thesis + Primary/Secondary Signature先成立；
- Graphic Block / Negative Space通过Icon Tests；
- Large / Medium / Small三层服务Hero Decisions；
- Material Contrast不被统一压成暗色哑光布；
- 武器与身体形成Hero Silhouette；
- 与普通人物同框时Visual Level Gap明显；
- 若Brief要求BOLD/EDITORIAL，执行结果不能被安全化；
- 失败：`TRANSFORMATION_COSTUME_GENERIC_FAIL / STYLE_FAMILY_DEFAULT_COLLAPSE / TRANSFORMATION_SPLENDOR_FLAT_FAIL / SPLENDOR_LARGE_SCALE_MISSING / COSTUME_GRAPHIC_STRUCTURE_FAIL / SPLENDOR_MATERIAL_FLAT / SPLENDOR_DETAIL_NO_HIERARCHY / TRANSFORMATION_BOLDNESS_SUPPRESSED_FAIL`。
