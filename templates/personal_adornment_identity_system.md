# Personal Adornment Identity System（人物个人装饰识别系统）

> **用途：** 给《断弦之歌》角色增加克制、有设计感、能帮助识别人物的个人装饰层。目标不是让所有人“什么都不戴”，也不是给所有人堆满耳环、项链、戒指，而是让装饰像真实人物长期选择的个人物件一样存在。
>
> **核心原则：** `Adornment should feel owned, not applied.`（装饰要像这个人自己的，而不是后期贴上去的。）

---

## 1｜适用范围

主要 / 反复角色默认执行完整 `Adornment Opportunity Review`；一次性SCOPED_CAST只做轻量判断。

装饰可包括：
- 耳钉 / 耳环 / 耳夹 / 耳骨夹；
- 项链 / 短链 / 长链 / 吊饰；
- 戒指 / 印戒 / 细戒；
- 手表 / 手链；
- 胸针 / 领针 / 领带夹 / 围巾针；
- 发夹 / 发针 / 发带中的小型金属或织物装饰；
- 眼镜 / 镜链（若角色设定适合）；
- 小徽章 / 旧纪念件 / 私人物件。

若物件承担剧情因果、线索、超自然机制或必须独立稳定识别，则**不再只算Adornment**，应升级为正式Prop / Character-linked Prop Authority。

---


### Existing Approved Protection
已有APPROVED Character Master不会因为本系统自动新增耳环、项链、戒指等装饰。旧角色先保持现有Authority并执行**Retroactive Adornment Audit**：从现有APPROVED Character Master / Closet / 当前Look提取已经真实存在的稳定装饰，登记为`GRANDFATHERED ADORNMENT IDENTITY`，不重设计；只有新角色、新Look、用户明确要求修订，或当前角色正式进入外观升级时，才新增/修改Adornment并由用户批准。

## 2｜不是人人必须戴，但“全员空白”不能成为默认

每个主要 / 反复角色必须明确：

`Adornment Strategy = SIGNATURE / ROTATING / FUNCTIONAL / MINIMAL / INTENTIONAL_NONE`

- `SIGNATURE`：1件长期稳定的个人标志装饰；
- `ROTATING`：从角色Closet的`Rotation Pool`中按LOOK / 场合 / 状态轮换1–2件克制配饰；不能把“可轮换”当成每集随机换；
- `FUNCTIONAL`：手表、眼镜、领针等功能与装饰合一；
- `MINIMAL`：只保留很小的一处设计点；
- `INTENTIONAL_NONE`：明确不戴，且由人格 / 职业 / 阶段 / 生活状态支持。

**INTENTIONAL_NONE是设计决定，不是省略字段。**

### Ensemble Gate
如果同一组主要角色全部 `INTENTIONAL_NONE`，必须检查是否真有统一剧情原因；否则判：
`ADORNMENT BLANK CAST FAIL`。

## 3｜Adornment Identity Card（个人装饰身份卡）

正式Character Master生成前，主要/反复角色至少记录：

```text
Adornment Strategy:
Primary Signature Adornment:
- Category:
- Placement:
- Scale:
- Shape / Motif:
- Material:
- Finish / Wear:
- Personal Meaning / Habit:
- Visibility Priority:

Optional Secondary Adornment:
- Category / Placement / Scale:

Rotation Pool（ROTATING时必填）:
- AC-__｜Wear Conditions=...｜LOOK Binding=...
- AC-__｜Wear Conditions=...｜LOOK Binding=...
Current Active Adornment:
Current LOOK Binding:

Adornment Density:
Asymmetry Rule:
Wardrobe Relationship:
Hair Relationship:
Face / Neckline Relationship:
Closest Existing Character:
Collision Difference:
Forbidden Generic Accessory Pattern:
```

### 设计重点
装饰差异优先来自：
- **位置**：左耳 / 右耳 / 颈部 / 手部 / 领口 / 发间；
- **尺度**：极小 / 中小 / 单点强调；
- **形状**：几何、旧式雕花、细链、印戒、针状、片状等；
- **材质**：旧银、黄铜、珐琅、木、皮革、磨砂玻璃、织物、低调金属；
- **佩戴习惯**：只戴一侧、长期不摘、藏在衣领下、工作时摘掉、与围巾固定使用；
- **磨损状态**：维护精良 / 老旧 / 修补 / 有生活痕迹。

颜色不是主要差异来源。

---

## 4｜克制设计规则

### 世界观与年代适配
- 日常装饰应落在20世纪70–90年代欧洲现实审美光谱内；
- 可以精致、有个性，但不默认当代网红微珠宝、品牌Logo堆叠、赛博饰件或现代潮牌符号；
- 旧银、黄铜、珐琅、旧表、细链、发针、领针、印戒、旧玻璃等只是材料/形态方向示例，不是固定清单。

### 推荐密度
- 默认：**1个Primary + 0–1个Secondary**；
- 允许局部更丰富，但必须有明确人格/职业/场合理由；
- 日常角色不默认“耳环 + 项链 + 三枚戒指 + 手链 + 胸针”全套上身。

### 设计感来自
- 不对称；
- 比例；
- 负形；
- 佩戴位置；
- 材质反差；
- 与发型 / 领口 / 手部的关系；
- 生活磨损与使用习惯。

### 禁止模板
- 所有女性统一细金耳环 + 细项链；
- 所有男性统一手表 + 印戒；
- 所有知识分子统一圆框眼镜；
- 所有圣谱者统一音符耳环；
- 为了“丰富”给所有角色机械加首饰。

---

## 5｜与服装 / 发型 / 脸部协同

装饰不是独立贴层，必须检查：
- 发型是否会遮住耳饰；
- 领口是否与项链长度冲突；
- 围巾 / 高领是否让颈饰完全不可见；
- 戒指 / 手表是否影响手套、持物、战斗动作；
- 胸针 / 领针是否破坏服装本来的剪影焦点；
- 装饰是否抢走Face ID / Hair ID / Eye ID的识别权。

**角色首先靠脸 / 发 / 眼 / 服装被认出，Adornment负责增加第二层个人记忆点。**

## 6｜四视图与专项资产

### DV-01 / TF-01
若装饰属于角色稳定身份：
- FRONT BODY必须看得出主要佩戴位置；
- FRONT FACE / SIDE FACE若涉及耳饰、眼镜、发饰，应保持一致；
- BACK若装饰存在背部固定点、发针、链条或后领结构，也必须一致。

### AD-01 Signature Adornment Detail（按需）
当某件非剧情关键装饰满足以下条件之一时，可生成`AD-01`高清局部资产：
- 经常在MCU / CU中可见；
- 结构很小，DV-01不足以锁定；
- 跨多集反复出现，容易漂移；
- 对人物识别非常重要。

`AD-01`仍是Character Appearance Authority，不自动升级为剧情Prop。

若后来承担剧情因果 → 升级Prop Authority，不让AD-01越权。

### AD-01 Requirement / Freeze Rule
Stage 02必须读取`character_asset_requirement_set.md`执行`AD-01 Need Test`。若本集镜头会清楚读出Signature Adornment、当前DV-01 / Current Look不足以稳定锁定、且该物件仍属于Character Appearance而非剧情Prop，则：
`AD-01 = REQUIRED / STAGE 03 / FREEZE-BLOCKING`。

Required AD-01必须真实生成、QC、用户批准后才能计入Episode Asset Freeze。Stage 04/05才发现同类缺口时输出`ADORNMENT_ASSET_GAP`并`FREEZE BROKEN(reason=adornment-detail)`，只补AD-01后Re-Freeze。

## 7｜Transformation Continuity

日常Adornment进入变身时必须明确：

`Adornment Transformation Rule = RETAIN / REMOVE / ABSORB / TRANSLATE / REPLACE`

- `RETAIN`：原物件继续真实佩戴；World State中的Owner / Placement / State持续不变；
- `REMOVE`：等同`REMOVE / STOW`，必须明确谁取下、Holder / Location / State是什么；只有Canon世界机制明确允许自动收纳时才可省略可见手部过程，**不得写“自然消失”**；
- `ABSORB`：只有Canon世界机制明确允许实体物件被Transformation结构吸收时使用；必须记录`Pre-Transformation Adornment State`与解除后的恢复规则；
- `TRANSLATE`：日常装饰的Motif / Placement被转译为变身礼服/发饰。若真实物件本体也发生物理转化，必须有Canon World Mechanic；否则原物件仍按RETAIN或REMOVE/STOW处理，变身结构只是视觉Echo；
- `REPLACE`：变身生成新的专属装饰。原日常物件仍必须另有`RETAIN`或`REMOVE/STOW`物理子规则，不能因为“被替换”就凭空消失。

Transformation开始前记录：
`Pre-Transformation Adornment Snapshot = Active AC IDs / Holder / Placement / State / Current LOOK Binding`。

De-Transformation结束时必须恢复**战斗开始前准确的Adornment State**，除非剧情明确在战斗中发生丢失、破损、转交或其他有因变化。

变身专属装饰可以音乐化，但不能代替Musical Eye Motif，也不能用堆音符首饰代替真正的Beauty Core设计。

---

## 8｜Reference / Continuity Rule

若稳定个人装饰在当前Storyboard / Video中**清楚可见且属于角色识别点**：
- 必须由Character Master / AD-01 / 当前Look Authority覆盖；
- 不能因为物件小就让模型随意消失、换边、换形；
- MCU / CU下若DV-01不可读而AD-01存在，AD-01可升级为`PERSONAL_ADORNMENT = CRITICAL`。

若当前景别根本看不清，则不机械追加AD-01。

---

## 9｜Hard Gates

### `ADORNMENT IDENTITY WEAK`
角色明明需要个人装饰层，但最终只是随机首饰或没有任何人格关联。

### `ADORNMENT TEMPLATE COLLISION`
多个主要角色共享同类别、同位置、同尺度、同材质逻辑，主要差异只剩颜色。

### `ADORNMENT OVERDESIGN FAIL`
装饰过多，抢走脸、发、眼、服装或变身Beauty Core的主次层级。

### `ADORNMENT CONTINUITY FAIL`
稳定装饰在四视图 / Storyboard / Video之间无因消失、换边、换形、增加或减少。

### `ADORNMENT BLANK CAST FAIL`
主要群像全部无装饰，而且没有统一的角色/世界观理由。

---

## 10｜一句话

> **人物可以克制，但不能因为“克制”就全部没有个人物件。真正高级的装饰不是多，而是像这个人自己选的。**
