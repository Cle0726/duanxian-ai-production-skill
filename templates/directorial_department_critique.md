# Directorial Department Critique（导演部门反驳协议） Current Authority

> **用途：** 给Director Interpretation做专业反驳，而不是多Agent角色扮演。每个Critique必须指出具体Scene事实、风险与建议，不允许泛泛说“更电影化”。


## Critique Rules
- 不得因为“AI模型难生成”否决导演Option；那属于后续Execution Translation。
- 不得越权改Story Canon。
- 不得把个人部门偏好冒充导演结论。
- 每个Concern必须可追溯到Audience State / Character Truth / Visual Logic / Sequence Logic中的至少一项。
