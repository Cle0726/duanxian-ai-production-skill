# Story Lock｜Canon Boundary Compatibility

> **Current Rule：** `story_lock_template.md`现在只负责Stage 01中的**Canon边界**，不再是“Stage 01完成模板”，**不能单独完成Stage 01**，也不能单独把流程送入Stage 02。完整Stage 01必须执行：`source_narrative_parse.md → screenplay_adaptation_engine.md → screenplay_lock_template.md`。

## Locked Story Facts｜不可静默改动
- 核心事件：
- 人物动机：
- 人物关系：
- 世界规则：
- 因果结果：
- 关键Reveal / Setup / Payoff：
- 必须保留的关键对白/信息：

## Adaptation Flex｜允许改表达，不改Canon
- Scene Split / Merge（必须保持因果与Reveal意义）；
- 重复信息压缩；
- Internal Thought外化；
- 普通对白口语化/压缩；
- 视觉化/声音化；
- 非关键连接动作；
- 纯重复文学修辞删除。

## Director Flex｜Stage 02才拥有
- Shot / Cut / Camera / Lens / Focus；
- Blocking / Axis / Screen Direction；
- Storyboard / Previs；
- 具体视听揭示策略。

## Compatibility Gate
- `Story Lock`存在但没有`EPISODE SCREENPLAY LOCKED` → `LEGACY_STORY_LOCK_ONLY_GAP`；
- 不得把`Story Lock = PASS`解释为`Stage 01 complete`；
- Existing Project按`existing_project_migration.md`做差量补齐，不追溯推翻已Approved Video。
